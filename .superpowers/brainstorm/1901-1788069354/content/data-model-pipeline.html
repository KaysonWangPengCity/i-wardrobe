数据模型 + 推荐流水线

① IndexedDB 表(Dexie)

6 张表,全部本地
items · 衣物单品
id, imageBlob, category(Top/Bottom/Outerwear/Shoes),
subCategory(T恤/衬衫/牛仔裤/西装…), color, season, thickness,
style(casual/formal/street…), brand?, material?,
createdAt, lastWornAt, wearCount, affinityScore
outfits · 穿搭快照(每次推荐产出)
id, date, itemIds[4], reason, aiRanking, weather{temp, condition}, feedback(liked/disliked/neutral)
wearLog · 实际穿着记录
id, date, itemIds[], eventType(worn/dryCleaned/discarded)
styleProfile · 风格画像
id(单条), preferredStyles[], colorPalette[], avoidedColors[], warmthBias(0-1), notes
settings · 用户配置
id(单条), apiKey, apiProvider, location, units, notificationTime, outfitComponents[4]
weatherCache · 天气缓存
date, location, tempHi, tempLo, condition, icon, fetchedAt

② 每日推荐流水线(方案 1:规则 + AI 重排)

从早晨打开应用到看到今日穿搭
1
获取天气
WeatherService 拉 Open-Meteo → 温度区间 + 晴雨 → 缓存到 weatherCache
2
规则过滤
纯函数 filterByWeather(items, weather) → 剔除季节不对/厚度不匹配/被标记丢弃的单品 → 按品类分桶(Top/Bottom/Outerwear/Shoes)
3
候选组合生成(规则打分)
笛卡尔积枚举 + 硬约束剪枝 → 色彩兼容表 + 品类配对规则 + 近期穿着天数(≥3 天前才允许) → 按打分排序取 Top 20 候选
打分 = 色彩谐和 × 0.35 + 品类适配 × 0.25 + 轮换分 × 0.2 + 亲和分 × 0.1 + 风格匹配 × 0.1
4
AI 重排(文本模型)
Prompt = 天气 + 20 候选清单(每项:品类/颜色/风格) + styleProfile + 近 7 天穿的什么 → 让 LLM 选最优 3 套并给推荐理由
5
展示 + 记录 + 反馈
渲染今日推荐卡片 → 用户点赞/换掉/标记"实际穿了" → 更新 outfit + wearLog + 每件单品的 affinityScore
